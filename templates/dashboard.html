Tableau Visualization Datasets Ready

We have processed and formatted three custom-engineered CSV datasets in the data/processed/ directory that are fully optimized for direct import into Tableau Desktop or Tableau Public:

tableau_matches_clean.csv Contains match metadata, cities, dates, teams, toss decisions, winners, margins, and umpires.
tableau_team_stats.csv Pre-aggregated records of total matches, toss wins, match wins, and percentage correlations for all 13 teams.
tableau_venue_stats.csv Records average matches played, batting first wins, and chasing success ratios for stadium layout reports.

How to view in Tableau:

  1. Launch Tableau Desktop / Public.
  2. Select Connect to a File → Text File.
  3. Open any of the CSVs in the data/processed/ folder.
  4. Create a Dashboard mapping:
    • Geographic maps using city and venue.
    • Lollipop Charts for top-winning teams.
    • Dual-axis charts for Toss win-loss influence.
